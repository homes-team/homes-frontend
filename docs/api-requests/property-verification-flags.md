# 매물 목록·상세에 인증 여부 내려주기 (백엔드 요청)

프론트는 매물 카드·목록 행·상세에 인증 마크를 붙이도록 만들어 두었다.
등기부등본(집주인) 인증과 중개사 현장 인증은 확인하는 대상이 달라서 마크를 따로 둔다.

## 현재 동작
- **상세**: 매물 응답에 인증 값이 없으면 `GET /properties/{id}/verifications`
  (`isOwnerVerified`, `isRealtorVerified`)를 따로 불러서 쓴다. 지금도 동작한다.
- **목록(카드·검색 목록)**: 목록 응답에 값이 없으면 마크를 보여주지 못한다. 목록은 매물이 많아서
  매물마다 위 API를 부를 수 없다.

## 요청
목록/지도/상세 응답에 아래 두 필드를 추가해 주세요 (기본값 `false`, 인증이 `APPROVED`가 되면 `true`).

| 필드 | 의미 |
| --- | --- |
| `isOwnerVerified` | 등기부등본(집주인) 인증 완료 |
| `isRealtorVerified` | 중개사 현장 인증 완료 |

- 대상: 매물 목록(`PropertyListRespDto`), 지도 검색, 매물 상세(`PropertyDetailRespDto`), 가능하면 찜 목록·최근 본 방.
- 필드 이름은 `GET /properties/{id}/verifications` 응답과 같게 맞췄다. 다른 이름을 쓰면 알려 주세요.
- 값이 응답에 들어오면 프론트는 그 값을 우선해서 쓰고, 상세에서 따로 조회하지 않는다.

## 안내 문구
- 값이 `false`인 매물 상세에는 "아직 등기부등본 인증이 안 된 매물이에요!",
  "중개사 현장 인증이 안 된 매물이에요!"를 보여준다 (매물 등록자 본인에게는 등기부등본 등록 카드를 보여준다).
- 응답에 값이 없거나 조회에 실패하면 마크도 안내도 보여주지 않는다 (미인증으로 오해하지 않도록).
